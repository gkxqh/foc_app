# v1.3.0：扫码登录 & 开发者选项

距上个版本又攒了一波实用更新，推荐所有同学升级 🎉

## 📲 全新：扫码登录

已登录的设备扫一扫，新设备即可授权登录：

- 个人中心新增「扫一扫」入口，扫待登录设备出示的二维码即可授权
- 确认前会展示出码设备的平台与脱敏 IP，**二次确认才生效**，扫错也不怕
- 二维码 120 秒过期，且不含任何凭证信息，被拍下也无法盗号；确认后登录凭证 5 分钟内未领取自动作废

## 🛠 全新：开发者选项

- 个人中心新增开发者选项页，提供**只读诊断信息**查看与一键复制，反馈问题更方便
- 支持在宽屏/桌面端**强制预演手机 / 侧栏 / 双栏布局**，不用来回拉伸窗口
- 工单详情页「无需确认直接结束工单」收进开发者选项实验开关，普通用户界面更清爽

## 🌐 网页端适配优化

优化 Web 端窗口尺寸分级（window class）判定逻辑，浏览器缩放窗口时手机/侧栏/双栏布局切换更自然。

## 📦 下载

- Android：按设备架构选择 APK（不确定就选 arm64，近几年的手机基本都是）
- macOS：`foc_app_v1.3.0_macos.zip`，Intel / Apple Silicon 通用  
  最低系统要求：macOS 12 (Monterey)  
  首次打开若提示“无法验证开发者”，在终端执行 `xattr -cr /Applications/云上飞扬.app`，或在 系统设置 → 隐私与安全性 里点击“仍要打开”
