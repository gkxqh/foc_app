平面 UI 风格解析与示例

同一世界观下，两款游戏演化出两条鲜明的平面设计路线：方舟以近黑底色、高层级对比与警戒亮色构建"深空终端"质感； 终末地转向黑白灰基底、工程图纸标注与等高线母题，呈现"开拓勘探"的控制台气质。本页拆解两者要点，并各给出一块仿游戏界面。

SECTION 01 // ARKNIGHTS

明日方舟 · 深空终端风格

核心是「极高的层级对比」：近黑深灰底 + 纯白文字 + 大量背景模糊，再以符合世界观的警戒亮色（青蓝、橙、稀有度金）做视觉引导； 形状上偏爱单侧斜切角、平行四边形斜切块与细白描边，配合条形码、序列号与英文微标签营造工业感。 背景图层还常压着巨型水印字——描边英文或大号无衬线中文，以缓慢平移、字距收缩的方式动画入场。

SECTION 03 // ENDFIELD

终末地 · 工程图纸风格

大面积黑白灰打底，警戒黄一色独大做点缀与引导——工程机械气质；等高线地形图、尺寸标注线、注册十字与切割虚线 把界面变成一份"勘探工程文件"。更扁平、更内敛，去装饰化。

SECTION 05 // SIDE BY SIDE

对比总结 · 一套骨架，两种气质

两款游戏共享同一套工业设计基因，只在"底色、点缀色与制图语言"上分岔。

维度 DIM明日方舟 ARKNIGHTS终末地 ENDFIELD
基底色调近黑深灰（#141418 系），白字高层级对比，弹窗普遍背景模糊黑白灰大面基底；另有"图纸纸感"亮色主题，扁平少投影
点缀色青蓝 #43B8FF（主操作）、警戒橙、稀有度金，多色但克制警戒黄 #FFD800 一色独大，兼作背景色块与视觉引导
形状语言单侧斜切角矩形、平行四边形斜切标签、细白描边切角 + 1.5px 粗描边 + 角标括号，硬投影"贴纸"卡片
装饰母题条形码、序列号、警戒斜纹、十字标、背景巨型水印字（描边英文/大号中文，带平移与字距入场动画）等高线地形图、尺寸标注线、注册十字、切割虚线、色标条
字体气质思源黑体 Heavy + Chakra Petch 科技体，大字距微标签特粗黑体大标题 + 等宽工程标注（坐标/编号/比例尺）
界面隐喻深空观瞄终端（Diegetic：看板投影）工程机械控制台 + 画内 HUD（产线可视化、勘探 HUD）
SHARED DNA // 切角形状语言 警戒亮色点缀 工业 / 工程制图感 中英混排微标签 条码与序列号 高信息密度 · 浅层级
